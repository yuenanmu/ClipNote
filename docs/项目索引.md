# ClipNote 项目索引

> 本文记录已确认需求和规划入口，不代表功能已实现。任务授权、进度、验收与实际验证统一见[任务清单](任务清单.md)。

## 1. 目标与目录

ClipNote 面向个人 Windows 使用，把视频字幕或已有文本整理为忠实、详细、层级清楚且可追溯的 Markdown 笔记。用户可以在 App 内阅读标题树与正文，保存到指定本地目录，也可以自行使用 Obsidian 等外部编辑器。

| 位置 | 用途 |
|---|---|
| `D:\Obsidian\Obsidian\10-项目\ClipNote` | 独立项目根目录；统筹需求、架构、任务及各 agent 交接 |
| `project/` | 后续应用源码、测试、依赖清单及构建配置；当前为空，不另建 Git 仓库 |
| `docs/` | 项目规划与协作事实入口 |
| `prompts/` | 对话入口参考，不构成执行授权 |

## 2. 已明确确认的首版范围

| 编号 | 能力与可观察结果 | 确认依据 |
|---|---|---|
| R01 | 独立 Windows App；文件分析及本地阅读不要求安装或打开 SmartSub、Obsidian | 用户确认范围并要求三者解耦 |

| R04 | API 接入和 ChatGPT 订阅登录都必须首版可用；API 可配置地址、模型与密钥 | 用户明确两者必须纳入首版 |
| R05 | 仅整理来源，保留关键论点、论据、例子和限制；有意义的标题层级附实际时间戳或段落引用 | 用户选择仅整理来源，不补外部知识 |
| R06 | App 内可折叠、可点击定位的 Markdown 标题树及正文；首版只读，修改通过可选外部编辑器完成 | 用户确认本轮提出的范围 |
| R07 | 用户选择本地目录；保留来源与生成版本，重新分析不覆盖人工修改过的 Markdown | 用户选择本地文件与版本保留 |
| R08 | 服务不可用、额度或权限不足时暂停；手动重试或切换，保留已完成阶段，不自动转用付费 API | 用户选择手动切换 |
| R09 | 检测已有 SmartSub；缺失时用户点击下载官方安装器，完成一次安装后连接 CLI；可选择安装位置 | 用户接受引导一次安装 |
| R10 | 已有字幕优先；确需模型或引擎时展示用途、下载信息及位置，确认后按需下载 | 用户选择按需确认下载 |
| R11 | 网站下载兼容沿用 SmartSub；ClipNote 重点验收 CLI 调用、任务跟踪、字幕读取及异常，用上游支持的代表链接验证 | 用户最新确认优先 CLI，无需提前列网站清单 |

阅读文件不触发 AI 请求。分析前说明来源文本将发给所选服务；首次连接和切换时显示接收方。正文、凭据和令牌不进入 Git 或普通日志。

## 3. 本次授权与排除范围

当前只授权需求整理、项目文档和本地 Git 准备。使用已有独立仓库：在 `main` 留下仅含说明、模板和忽略规则的初始化基线，再在 `docs/project-kickoff` 完成本轮文档提交，结束后停止等待审阅。

本次不编写业务代码、不安装依赖或运行程序、不运行构建或测试，不创建远程仓库、推送或合并分支。首版任务是实施规划，不是自动开工许可。

首版暂不包含：内置 Markdown 编辑或拖动树节点改写、外部知识补全、PDF/DOCX/OCR、云同步、多用户账户、自研识别引擎、复制 SmartSub 全部界面、自行维护其 Windows 便携发行版。扩展这些能力需另行确认。

## 4. 技术决策与环境

| 决策 | 选择及理由 | 边界 |
|---|---|---|
| D01 桌面与界面 | Electron + React + TypeScript；Vite 组织开发，electron-builder 负责后续 Windows NSIS 打包 | 用户将选型交给执行者；具体版本在兼容性验证后锁定，本轮不安装 |
| D02 AI | `@earendil-works/pi-ai`；API 与 ChatGPT 登录分别适配统一文本接口 | v1.4.0 为研究基线，库有实现不等于目标账号已可用 |
| D03 来源 | 文件适配器与 SmartSub CLI 适配器并列 | 首版不采用 MCP，不抓取窗口或读取其私有数据库 |
| D04 SmartSub | 官方 buxuku/SmartSub v3.11.0 自动化接口；接入已有安装或引导官方下载 | 用户 fork 3.7.0 早于当前 CLI；CLI 依赖完整 SmartSub 运行环境 |
| D05 保存与阅读 | 本地独立版本；Markdown AST 驱动标题树及正文定位 | Obsidian 可选，不强制某个笔记库作为输出位置 |
| D06 资源 | 单个活动任务、按需启动、字幕优先、按需模型、结束轮询 | 尚无实测数值，不承诺具体内存占用 |

开发机已只读检查：Windows X64，系统版本字符串 `10.0.26200`；Node `v24.14.1`、npm `11.11.0`、Git `2.50.0.windows.2`。这不等于安装包已兼容所有 Windows。

pi-ai v1.4.0 声明 Node `>=22.19.0`，必须同时检查 Electron 内置 Node。具体 Electron、React、打包器及测试工具版本在创建依赖清单时固定并提交锁文件。测试工具和真实脚本由 T03 建立，T02 的最小接入验证独立记录；当前均未创建或运行。

源码、测试入口及启动/验证/打包命令：**尚不存在，待后续任务创建并实际核实**。未来执行目录为 `project/`；文档与 Git 操作在根目录。不能照抄 SmartSub 命令作为 ClipNote 命令。
