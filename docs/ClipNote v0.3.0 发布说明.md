# ClipNote v0.3.0 — Windows x64 便携版

ClipNote 是一款 Windows 桌面应用，可将字幕和文本整理成 Markdown 笔记，并在正文和脑图之间切换阅读。

### 本版更新

- 新增多链接视频队列，支持获取现有字幕与本机转写交错进行。任务完成后可预览和打开字幕，原字幕可一键复制到资料文件夹。
- AI 整理同时显示已处理文件数和当前文件的分块进度。整理面板底边可拖动并记忆高度。
- 支持保存多套 API 服务，整理时可临时切换。内置标准、简略、详细和行动清单四套提示词，支持自定义。
- 资料和笔记沿用统一的浅蓝青渐变，内容区和下拉菜单采用圆角。文件侧栏可收起，文档目录可拖动调整宽度。
- 更新桌面图标。蓝青折页笔记置于白色圆角底板上，带轻阴影。

### 使用方法

下载 Windows x64 便携 ZIP，完整解压后双击 `ClipNote.exe`。AI 整理需要配置兼容 API 或使用应用内的 ChatGPT 订阅入口。SmartSub 是获取视频字幕或转写时可选的独立工具。

本包未签名。附件中的 `.sha256` 可用于核对下载文件。内附 Sign-in with ChatGPT DevKit 适用非商业许可，见包内 `licenses`。
