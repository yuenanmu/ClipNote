# ClipNote Windows 候选版使用说明

## 系统要求

本候选包含 Windows x64 运行时，目标为 64 位 Windows 10 或 Windows 11；尚未在其他电脑或 Windows on ARM 上验收。链接获取、服务登录和 AI 请求需要可用网络。SmartSub 的组件、模型及磁盘空间要求依其实际安装选择而定。

## 准备与启动

将整个候选文件夹复制到本机可写位置，双击 `ClipNote.exe`。程序自带 Electron 运行时，无需另装 Node.js。请保留文件夹内的全部文件；这是未签名、尚未完成跨电脑验收的候选版。退出程序后删除候选文件夹即可移除程序；用户数据保留在当前 Windows 用户的 `%APPDATA%\ClipNote`，请先自行备份需要保留的数据。

## 导入资料与整理

在资料区选择本地 SRT、VTT、TXT 或 Markdown，选择笔记目录。设置中的“AI 服务”可配置兼容服务、模型和密钥；服务可能收费。也可在“ChatGPT 订阅”中通过浏览器授权并选择模型，该功能的真实产品流程仍待验收。发送前核对账户、服务、模型和来源，整理完成后按界面提示保存并在笔记区阅读。

## 链接与 SmartSub

链接获取依赖另行安装的 SmartSub；本候选不包含 SmartSub、下载组件或转写模型。在设置中选择已有 SmartSub 安装目录，或使用界面提供的官方入口自行安装。下载组件与本地模型需在 SmartSub 中按需准备。已有字幕优先；需要转写时请先确认资源和耗时。完成后将字幕导入资料区，再选择 AI 服务整理。

## 常见问题

- 程序无法打开：确认已完整解压到本机可写目录，检查系统提示和安全软件；本候选尚未进行代码签名。
- 找不到 SmartSub：在设置中手动选择安装文件夹，确认安装完整及其版本兼容。
- 登录或模型列表失败：检查网络、账户资格及服务设置；请勿将令牌、密钥或授权回调地址发送给他人。
- 结果无法保存：检查目标目录是否可写、同名文件是否被修改；保留待保存结果并按界面选择其他位置。

本候选包含 Sign-in with ChatGPT DevKit，许可仅允许非商业用途；详见 `licenses` 文件夹。外部服务有各自的使用条款。真实账号、链接、转写、长文本和另一台电脑的完整流程尚未完成验收。
