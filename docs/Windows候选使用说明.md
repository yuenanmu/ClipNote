# ClipNote Windows 候选版使用说明

## 系统要求

本候选包含 Windows x64 运行时，目标为 64 位 Windows 10 或 Windows 11；尚未在其他电脑或 Windows on ARM 上验收。链接获取、服务登录和 AI 请求需要可用网络。SmartSub 的组件、模型及磁盘空间要求依其实际安装选择而定。

## 准备与启动

将整个候选文件夹复制到本机可写位置，双击 `ClipNote.exe`。程序自带 Electron 运行时，无需另装 Node.js。请保留文件夹内的全部文件；这是未签名、尚未完成跨电脑验收的候选版。退出程序后删除候选文件夹即可移除程序；用户数据保留在当前 Windows 用户的 `%APPDATA%\ClipNote`，请先自行备份需要保留的数据。

## 首次配置

1. 点击左侧“笔记”，使用“打开笔记文件夹”选择一个可写文件夹，生成的笔记保存在你选择的位置。应用设置和运行数据保存在 `%APPDATA%\ClipNote`；删除程序文件夹不会删除笔记或这些数据。
2. 打开左侧“设置” → “AI 服务”，填写服务地址、密钥和模型名称，点击“保存设置”。“测试连接”会向服务发送固定短文本，可能产生费用；保存本身不发送请求。也可使用“ChatGPT 订阅”登录并获取模型，但订阅的真实产品流程尚待验收。不要向他人提供密钥或登录回调地址。
3. 如需从视频链接获取内容，打开设置 → “SmartSub”。本候选不包含 SmartSub、下载组件或转写模型：请通过“打开官方下载页面”自行安装 SmartSub，再用“选择安装文件夹”连接并检查页面显示的版本、接口和下载组件。缺少下载组件时，在 SmartSub 中准备后点击“重新检测连接”。
4. 如果没有现成字幕且需要本地转写，请先在 SmartSub 中按其说明准备本地引擎和模型；模型不会由 ClipNote 自动下载。在 ClipNote 的 SmartSub 设置中选择已就绪的引擎和模型，或使用 SmartSub 的本地默认配置。转写可能耗时并占用较多资源。

## 从链接到笔记

1. 进入左侧“资料”，点击右上方“视频链接”，粘贴链接并点击“确认并开始获取字幕”。SmartSub 会访问链接并下载视频及字幕；支持的网站以 SmartSub 为准，播放列表可能占用较多空间。
2. 完成后点击“使用字幕”。若没有字幕，按界面检查本地转写资源，再确认开始转写，完成后点击“使用转写字幕”。若找到的字幕格式暂不支持，先在 SmartSub 中转换为 SRT 或 VTT。也可以在资料页点击“打开文件”，选择本地 SRT、VTT、TXT 或 Markdown；单文件上限为 16 MiB。
3. 在资料页点击“AI 整理”，选择“整理服务”和笔记目标文件夹。使用 API 时点击“检查所选文件”，核对资料、服务、模型和保存位置后点击“确认发送并开始”；处理成功后会保存。使用 ChatGPT 订阅时一次只能处理一份资料，选择订阅模型并按提示确认发送；生成后在“待保存结果”中点击“恢复保存”并确认。服务可能收费。最后到左侧“笔记”中打开生成的 Markdown 阅读。

## 常见问题

- 程序无法打开：确认已完整解压到本机可写目录，检查系统提示和安全软件；本候选尚未进行代码签名。
- 找不到 SmartSub：在设置中手动选择安装文件夹，确认安装完整及其版本兼容。
- 登录或模型列表失败：检查网络、账户资格及服务设置；请勿将令牌、密钥或授权回调地址发送给他人。
- 结果无法保存：检查目标目录是否可写、同名文件是否被修改；保留待保存结果并按界面选择其他位置。

本候选包含 Sign-in with ChatGPT DevKit，许可仅允许非商业用途；详见 `licenses` 文件夹。外部服务有各自的使用条款。真实账号、链接、转写、长文本和另一台电脑的完整流程尚未完成验收。
