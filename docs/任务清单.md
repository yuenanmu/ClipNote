# 任务清单

> 任务授权、状态、验收和验证事实的唯一记录来源。初始没有已授权执行任务。
> 编号从 T01 开始，稳定不复用。删除或撤销任务保留简要原因，不用旧编号替代新任务。

状态：待开始 / 进行中 / 阻塞 / 已完成。状态不等于授权；新增任务先标“未确认”。

## 任务目录

当前为空。初始化时按已确认需求创建任务记录；不要把下面的字段说明当作任务。

## 每项任务的记录字段

- 编号与名称：
- 用户确认依据及已确认范围：
- 状态：
- 依赖任务：
- 验收条件：
- 相关模块/文件：
- 实际验证记录：检查时点、执行目录、命令或人工步骤、通过/失败/未运行、关键证据
- 未验证项或阻塞：
- 结果与关键取舍：
- 关联成果提交：可填已有提交，或注明收尾后按任务编号从 Git 查询；不为补本次提交自身哈希追加提交。

任务按需形成 T01、T02 等二级标题。小任务不要为每次微调新建任务。

## 完成标准

验收条件满足并有实际验证记录后才标“已完成”；仅实现完或提交完不算完成。人工验收尚未进行时如实保留未完成状态。
