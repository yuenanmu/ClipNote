## ClipNote Windows x64 预览版

ClipNote 可打开字幕或文本，整理为可以追溯来源的 Markdown 笔记。可以在正文与脑图之间切换，也可以并排查看。整理界面显示当前阶段和批量进度，失败时提供重试或保存恢复入口。

下载该版本的 Windows x64 便携 ZIP，在本地完整解压后双击 `ClipNote.exe`。随包附有使用说明、第三方声明和 SHA-256。SmartSub 为可选的独立软件。AI 整理需要配置兼容 API 或完成应用内订阅登录。

集中任务和统一保存入口仍在后续路线图。发布时填写已验证的 Windows 版本、签名状态和适用的真实服务限制。
