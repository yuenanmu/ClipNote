# ClipNote 第二版验证手册

本页列出待执行检查。2026-11-17 文档阶段核对了现有测试文件及运行入口。产品回归、模拟测速和真实请求均由对应开发任务执行，结果回填[当前 TODO](任务清单.md)。

## 准备

从 `project/` 执行。使用测试既有的隔离资料目录、合成账号/密钥、环回 API 和订阅替身。测试夹具沿用 `tests/integration/subscription-stream-fixture.ts` 与 `tests/e2e/batch-latency.test.mjs` 的接入方式，脚本化响应时序，记录每次收到的请求数。注入测试时钟以避免真实等待。对照每个分组使用相同的状态和输出断言。

使用一份较短 SRT 或 TXT 和一份能触发至少两个分块的中文长文。每份长文预先标注 5 个论点、5 个支撑、3 个例子和 2 个限制，横跨不同分块。评估时逐条检查归属、准确性与引用；合成输出用于控制流程，实机输出另由人工对照。

## 自动回归矩阵

| 用例 | 输入与操作 | 预期结果 | 执行入口 |
|---|---|---|---|
| V2-01 阶段事件 | 两路各返回标头、空帧、有效输出、完成 | 标头与首文本时间不同，空帧不会标记首文本。结束后显示校验与保存，报告相对计时 | API provider 单测，订阅适配和 stream 集成 |
| V2-02 失败报告 | 脚本在预检、首输出或接收中报错，另触发取消 | 每次只产生一次终态，时间报告保留已观察阶段。脱敏载荷不含测试密钥、全文或请求头 | 分析 Worker 单测和订阅 stream 集成 |
| V2-03 集中展示 | 由资料入口启动 API 单文件，在设置或阅读页切换后返回 | 同一任务继续推进，结果可在任务页直接打开 | workspace、batch 窗口 |
| V2-04 批次 | 三项含重复输入，中间一项出错，再取消 | 逐项显示已保存、异常或取消。只处理可重试项，重复计算规则延续首版，已保存项保持可打开 | batch、batch-latency 窗口 |
| V2-05 订阅保存 | 选合成账户、来源、子目录，确认。分别构造账户变化、目标变动和正常保存 | 账户变化拒绝旧确认。目标变化保护原文件并留下完整待存结果。正常完成仅一次生成并按预选位置保存 | subscription-task 单测和 subscription 窗口 |
| V2-06 保存重试 | 生成后注入写入失败和目标覆盖冲突。重启后从已有待保存结果恢复 | 明确冲突或失败。经确认后只写盘，模型调用计数保持不变，结果可打开 | workspace、subscription 和 batch 窗口 |
| V2-07 视频/P033 | 模拟链接获取、主动查询、无变化、转写完成、使用字幕与 AI 失败 | 当前任务显示查询结果。完成后原任务继续确认；AI 重试无重复转写。退出界面不丢失原 SmartSub 可恢复回执 | smartsub-task、smartsub-recovery 窗口 |
| V2-08 慢首响应 | 模拟响应头早到，首有效文本超过阈值；另测期限前到达 | 超过则 FIRST_OUTPUT_TIMEOUT，期限内继续。后续迟到事件不能保存 | api-provider、subscription-stream |
| V2-09 持续与停滞 | 首文本后按小于空闲期限的间隔持续输出至超过旧 API 60 秒；再以仅心跳模拟停滞 | 前者在新硬预算内成功，后者 STREAM_IDLE_TIMEOUT。心跳不推迟截止 | api-provider、subscription-stream、batch-latency |
| V2-10 硬截止与断流 | 持续有效输出跨硬期限，或提前断流且无完成事件；另注入输出上限 | 分别映射请求/文件截止和断流。仅明示上限可走有界修正或拆分；从不保存不完整结果 | api-provider、analysis-task、subscription-stream |
| V2-11 取消和迟到 | 分别在等待、接收、写入前及写入临界区取消，注入旧尝试返回 | 临界区前取消不新增笔记。临界区完成时如已提交则显示实际结果。旧结果不会影响新尝试 | analysis-task、subscription-task、batch 窗口 |
| V2-12 代理与失败 | 同一 mock 流用直连/正常代理/不可用代理，模拟 401、402、429、503 | 路径记录与代理实际到达一致。能区分权限、额度、限流及服务错误；推理请求不自动重发 | subscription-transport 与 T21 独立对照 |
| V2-13 优化条件 | 启用某项 T22 后测账户切换、引用越界、中断恢复 | 缓存失效或不命中，引用严格校验，仅有效块复用。对照记录请求次数与质量 | subscription-adapter、subscription-task、batch-reuse |

命令按任务运行。示例为 `node --test tests/unit/api-provider.test.ts tests/unit/analysis-task.test.ts tests/unit/subscription-adapter.test.ts`、`node --test tests/integration/subscription-stream.test.mjs`、`node --test --test-concurrency=1 tests/e2e/batch-latency.test.mjs tests/e2e/subscription.test.mjs`。提交前运行类型检查、构建及受影响的用例。T23 执行完整检查及隔离打包回归。[测试策略](测试策略.md)
