# T05 本地 Markdown 阅读器实施计划

> **For agentic workers:** 使用 superpowers:executing-plans，由当前主执行者连续实施；AGENTS 要求单写入者，其他 agent 仅在收尾只读审阅。任务清单统一记录授权、结果和验收。

**Goal:** 用户可直接打开本地 Markdown 或阅读归档版本，在离线窗口使用标题树、正文定位、来源查看与主动刷新。

**Architecture:** Worker 使用 unified/remark 解析同一份 mdast，给标题分配唯一锚点与根块索引；React 仅渲染白名单节点，不插入 HTML、不加载图片。主进程登记文件选择框或已验证版本产生的阅读会话，只接受会话/版本 ID；刷新重读已登记路径，外部打开和 HTTP(S) 链接必须主动点击。

**Tech Stack:** 沿用 Electron/React/TypeScript/Node test/Playwright；固定 unified11.0.5、remark-parse11.0.0、remark-frontmatter5.0.0、remark-gfm4.0.1，类型使用 @types/mdast4.0.4。

**Spec:** [M06](../../模块/Markdown阅读.md)、[T05](../../任务清单.md#t05--本地-markdown-阅读器)、[架构](../../架构.md)。用户已确认既有首版只读阅读范围，本轮明确批准 T04 合并并继续下一任务；无需重新选择已确认的产品范围。

## Global Constraints

- feat/reader 基线 b1b5880（T04 获准 no-ff 整合）；沿用 IDE 当前项目目录的独立功能分支和已安装运行时，不复制依赖/另建仓库。T05 不自动合并，不启动 T06。
- 同一 AST 驱动标题树与正文，代码块/frontmatter 不产生伪标题；重复、无标题和跳级标题必须可读。
- 直接打开 MD 不依赖导入解析、AI、SmartSub 或 Obsidian；支持空文件和既有编码，不改写正文。
- 阅读上限2 MiB、20,000节点、64层嵌套；超过明确提示，不截断假称完整；正文按根块分页，标题定位可切到目标页。
- 管理原始 HTML/脚本为文本，图片只显示替代说明，无 img/iframe/dangerouslySetInnerHTML；外链只允许已登记正文中的 HTTP(S)，无自动外部操作。
- 已归档正文通过 M05 验证后读取，来源引用仅定位该版本的来源片段；归档缺失/更换库时明确失败，保留当前阅读。
- 所有测试使用合成 Markdown、独占 userData/output，清理先核对所有权。保留真实 npm start 与原生窗口控件检查。

## Review Focus

- frontmatter、围栏/缩进代码、重复/跳级标题：标题树与唯一正文锚点一致。
- 非法 URL、raw HTML、SVG、图片和本地路径：无法执行脚本、发远程请求或越权打开文件。
- 刷新期间文件删除/变链接/编码损坏、库切换：固定错误，保留旧正文，会话仍可继续使用。
- 长文/深嵌套：Worker 超时和明确限制，标题跳转跨分页，不冻结主窗口。
- 归档 note.md 被外部编辑、原来源文件被删除：读取当前笔记并从归档查看真实来源，不重跑 AI。
