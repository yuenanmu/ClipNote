# T12 Windows 候选版实施计划

基线：main 1832fdc；工作分支 feat/windows-package。目标是在用户正常 Windows 桌面生成可搬运候选，真实账号和跨电脑验收单列。

1. 核对依赖许可、SmartSub 安装与模型获取责任；候选附 DevKit 非商业许可证及第三方声明，不捆绑未经确认可分发的 SmartSub 或模型。
2. 检查 Electron 运行时和打包工具可用性；选择可复现的 Windows 分发方式，记录版本、资源清单和许可。开发机可用的 Node 不作为目标机前提。
3. 先测试再调整打包运行路径：生产数据放用户可写目录，保留开发/隔离测试配置；确保主进程、preload、worker、渲染器及生产依赖均能从打包布局运行。
4. 打包、准备使用说明，在独立测试配置检查启动、重启恢复、错误反馈和合成工作流；以可用环境为准记录 Windows 版本和限制。
5. 更新任务、模块与交接，记录真实网络、另机测试、许可证及 T10/T11 尚未验证的缺口；阶段提交，未经批准不合并或发布。
