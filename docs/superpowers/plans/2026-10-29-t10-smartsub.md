## 分阶段工作与验收

1. **契约和运行环境**：核对现有 T02 文档及对应上游 CLI 接口、实际安装位置与版本；缺失条件写入任务清单，不把 help 测试写作完整任务验证。
2. **受控 CLI 与安装发现**：先补目标失败测试，覆盖安装发现/手选、中文空格路径、版本与资源缺失、命令白名单、JSON 边界、超时/取消及敏感信息保护；再实现受限进程调用和固定错误分类。
3. **任务协调与字幕来源**：测试稳定 requestId、真实任务 ID、查询/等待超时不误判取消、仅取消指定任务、字幕分页及损坏错误；实现阶段状态、重连、字幕优先及必要转写确认。保留已获得的资料和恢复位置，不结束共享后台。
4. **桌面接入**：受信任 frame 的 IPC、preload 白名单、链接入口、状态和下载/转写确认，接入现有文件/分析/保存链。测试重复操作、关闭窗口、超时失败、用户拒绝及同一个来源保存阅读。
5. **验证交付**：运行 `npm.cmd run typecheck`、`npm.cmd run build`、`npm.cmd test`、`npm.cmd run test:e2e`，使用独占临时目录、合成字幕和 CLI 替身。单独记录真实 Windows CLI、已有后台、上游支持链接、字幕优先、必要转写及保存阅读；如果程序/网络/资源或人工确认不可用，真实验证记未运行，不勾选 T10 主任务。同步架构、模块、问题记录及交接后按规范本地提交。
