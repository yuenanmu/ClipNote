# T10 联动体验与设置重做

用户明确要求重做割裂的 SmartSub 界面、低效操作和转写卡住体验，并建立统一配置入口。保持完整目标，不以局部兼容修复代替交付。基线 feat/smartsub / bcb1a7e，不合并、不推送。

## 需求和交互

1. 视频链接融入资料工作区，保留既有文件树、笔记导航和主区域结构。获取的字幕回到现有预览、AI 整理、确认保存及阅读流程。
2. 统一设置入口包含 AI 连接与 SmartSub；安装位置通过系统选择器保存、检测，显示当前配置、可用性和修复方式。引擎模型选择和资源说明集中设置；不能继续依赖聊天索取地址。
3. 任务自动更新，明确区分准备、下载、待确认转写、运行、失败、取消和未知连接状态。返回资料或设置不能丢掉任务；不把查询超时作为后台已结束。
4. 转写卡住需用实际任务身份与回执排查。长调用不阻止取消；重复点击不重复提交；失败重试保留原媒体；提交回执丢失复用原请求。

## 实现与规范

- App 保留统一壳；设置与视频内容作为主区域视图。拆分配置、来源输入和任务状态组件，不继续扩大单个 SmartSubPanel。
- 主进程控制安装、资源和任务；renderer 仅发受约束参数。持久状态与 UI 展示分开。自动查询不重叠，失败有退避，终态停止；页面卸载清理监听，不取消共享后台。
- 核查当前重复的 system.info 身份探测链及转写串行队列，按实测减少重复成本，同时保留安装/profile 校验。
- 不自动升级、下载模型、发送私人字幕到服务；资源和转写需用户明确确认。保留已有 AI/文件工作流及私人配置；只写 ClipNote 子模块。

## 测试与验收

- 先写目标失败测试：自动查询、慢查询不重叠、临时错误后恢复、终态停止、卸载不再更新；取消和重复提交、重试回执丢失。
- 窗口验证：设置入口及配置持久化、文件与视频共享侧栏、离开页面再回到任务、无需手动查询即可完成、错误与取消可操作、窄窗口布局；截图检查。
- 类型检查、构建、串行离线测试、完整窗口回归；真实 SmartSub 任务单独验证。安装不可访问仅阻止相应实测，不推断程序未安装，不阻止独立开发。
- 总验收须覆盖设置、融合 UI、操作流和实际转写问题；未验证不标完成。

## 当前证据

- 旧 App 用提前 return 替换整个壳；旧 Panel 只手动查询，转写 running 错标为获取字幕。
- 主进程一次任务操作重复发现安装并多次 system.info；转写 submit/refresh/cancel 共用串行队列。尚未证明这些是用户本次卡死的根因。
- 已保存配置及本地 journal/transcriptions 存在；当前执行环境仍无法读取所配置安装目录。后续只读查询真实状态，不自动重启或取消用户任务。

工作台整合、独立设置、引擎模型持久选择、自动资源检查、状态观察、慢查询取消与终态重试观察已实现。引擎模型保存只改变 ClipNote 专用配置；选择损坏时仍显示资源供用户重新保存。合成 CLI 窗口覆盖普通字幕、无字幕转写、保存配置、切换视图、慢查询取消及重试；具体结果以任务清单为准。

### 身份检查优化（97228b9 后）

将原先“先查询身份、随后重新发现安装并再次查询身份”改为一次获取操作连接：连接含安装/profile 摘要与捕获同一安装的受限调用函数。任务层校验持久绑定后，仅使用该连接执行操作，不跨操作缓存身份。保持旧记录摘要算法不变。先验证每次操作只有一次连接检查、不会调用未绑定路径，以及身份变化仍拒绝恢复和取消，再运行 SmartSub 定向与完整回归。

身份连接优化已实现，验证与阶段提交见任务清单。每次操作重新核实，不缓存外部身份，不保证原子锁定外部进程生命周期。
