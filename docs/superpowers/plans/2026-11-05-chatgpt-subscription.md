# T08 ChatGPT 订阅接入

## 目标与基线

从 main ca35c67 的 feat/chatgpt-subscription 实现单文件与 SmartSub 已导入来源的订阅整理。实机前置验证已通过，使用现有订阅额度。T08 完成需产品入口真实闭环和登录生命周期证据。

## 登录与网络

固定官方 DevKit 源版本 0a36fefeb913055c8c7a1a29b63d82b96b2e841a，保留许可及第三方声明。其许可限非商业用途，当前为个人本机开发，分发前另核适用范围。

在 Electron 可信进程执行 OAuth、身份校验及请求。使用系统网络代理通路，限制为官方授权和 API 端点，拒绝重定向。API Key 配置独立。加密存储由 Windows safeStorage 提供，不可用时明确失败。

设置提供登录、取消、状态、账户显示、模型列表、退出。前端只接收安全会话摘要，模型发送确认绑定当前账户和模型。退出和账户变化取消活动订阅请求。公开错误应覆盖权限、配额、网络、取消和流未完成。

## 分析与保存

订阅适配器实现现有 AnalysisAdapter，复用分块、结构和引用校验及 Markdown 输出。在当前文件工作台入口接入，支持已导入 SmartSub 字幕。发送前确认服务、账户和模型，生成结果经用户确认保存后进入现有阅读流程。请求使用 store=false、stream=true，只有 response.completed 才接受结果，失败保留来源。

## 测试与提交顺序

先登记 M01/M04、架构和测试策略的具体接口及行为，再编写失败测试与实现。

离线测试覆盖身份验证错误、加密不可用、取消、刷新失败、重启恢复、账户或模型变化、权限额度错误、网络中断、未完成流和来源结构校验。窗口测试覆盖设置、发送确认、失败反馈、取消、保存阅读，使用合成内容和服务替身。

执行类型检查、构建、离线及窗口回归。实际应用通过用户正常浏览器授权，用合成内容验证订阅整理、重启后恢复及保存阅读。无法触发的刷新或失败条件明确登记。阶段成果本地提交，合入 main 另待授权。
