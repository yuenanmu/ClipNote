# ClipNote 第三版开发计划与 TODO

第三版围绕资料归档、视频链接和 AI 整理，提供持续可见的任务状态、可切换的 API 配置，以及统一的 Windows 桌面样式。开发基线为 `main` 的 `61889ed`，实施分支为 `feat/v3-workflow`。

| 任务 | 行为与验收 |
| --- | --- |
| 目录宽度 | 嵌入式文档目录右侧支持鼠标与键盘。默认 210 像素，保存用户选择。窄窗口约束有效宽度，收起和窗口调整保留偏好。 |
| 视频队列 | 一行一个链接，每次最多 100 条，队列最多保留 200 项。下载及本机转写分别有一个活动位置。优先用已有字幕，按批确认自动转写。缺模型及明确失败留在对应条目，其他可运行条目继续。 |
| 恢复与原文 | 侧栏显示队列摘要。完成项可预览、选字幕及打开原文。队列在本机加密保存链接；重启先查询已提交项，等待用户继续后再投递未开始项。提交状态不明时使用原请求标识恢复。 |
| 复制到资料 | 在 AI 整理旁直接复制当前字幕字节。没有根目录时提示选择。相同内容复用现有文件，冲突时添加编号。定位副本后当前资料及笔记关联仍指向原文。 |
| AI 整理进度 | 批量以终态资料数计算已处理，并列出各结果数。文档用原计划总块数、验证完成块数和实际整理/保存阶段。API 和订阅调用共用计数来源。 |
| 多套 API | 添加、编辑、删除、测试、查询模型和选择默认服务。首档可沿用旧加密配置。整理前可临时切换。开始时按服务 ID、版本锁定整批凭据，单独恢复保存无需重新发送。 |
| 界面 | 资料、视频链接与队列、设置、旧归档和笔记沿用同一浅蓝青绿主题，统一圆角、半透明卡片和按钮状态。原文、Markdown 和编辑区使用低反差的浅蓝青渐变底，脑图使用深蓝青绿画布。下拉展开菜单也采用蓝青底和圆角，保留键盘选择。 |
| 整理面板 | 显示整理服务、笔记位置和提示词模板，保留关联已有笔记入口。确认和进度各自显示当前相关信息。下边缘可拖动，支持方向键及 Home / End，记忆高度，窄窗口为原文留出空间。 |
| 提示词模板 | 内置标准、简略、详细和行动清单。选择后同时用于 API 和订阅整理，支持查看、另存自定义模板、修改自定义模板和记住上次选择。原有补充要求作为自定义模板保留。 |
| 侧栏开关 | 文件侧栏可随时隐藏和显示，记住上次状态和展开宽度。切换时保留当前工作区。 |

## 使用入口

- 从侧栏「视频队列」粘贴链接，选择无字幕时是否自动转写。完成后可先预览字幕，再打开原文。
- 从原文页的「AI 整理」旁点击「复制到资料」。副本出现后可用「在资料中定位」。
- 从「设置 → AI 服务」管理默认服务。从「AI 整理」的「本次使用的 API 服务」切换当前任务的服务。面板底部的短横线可上下拖动。

- 「AI 整理 → 提示词模板」可直接选择模板。点击「查看 / 编辑」查看或保存自定义内容。
- 点击侧栏顶部的窗口图标收起文件侧栏。收起后从左上角恢复。
