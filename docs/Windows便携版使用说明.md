# ClipNote Windows x64 便携版

ClipNote 可将视频字幕和文本整理成 Markdown 笔记，并提供正文、脑图和双栏对照阅读。

## 下载和启动

适用于 Windows 10 / 11 x64。完整解压 ZIP 后，打开解压目录中的「ClipNote.exe」。程序自带运行时。当前构建未签名，Windows 可能显示发布者提示。

如需升级，解压到新的文件夹并从该目录启动。应用设置保存在当前 Windows 用户的 `%APPDATA%\ClipNote`，原文和笔记保存在你选择的目录。可以把程序的快捷方式放到桌面。

## 使用方法

1. 在左侧「资料」选择文件夹，或点击「打开文件」读取 SRT、VTT、TXT 或 Markdown。文件的字幕时间、文本行号和原文都可查看。
2. 在左侧「笔记」选择可写的笔记文件夹。生成的结果是普通 Markdown，可切换正文、脑图和对照，也可在其他 Markdown 编辑器中打开。
3. 在「设置 → AI 服务」添加兼容 API，或使用「ChatGPT 订阅」入口。打开「AI 整理」选择服务和提示词模板，核对发送对象及保存位置后开始。订阅整理完成后在「待保存结果」中确认保存。
4. 从视频提取字幕时，在「设置 → SmartSub」连接已安装的 SmartSub。进入「视频队列」逐行粘贴链接，已有字幕优先。需要本机转写时，应先在 SmartSub 中准备引擎和模型。完成后打开字幕原文，点击「复制到资料」可原样归档。
5. 点击 ClipNote 标题旁的圆形按钮可收起文件侧栏，收起后从窗口左上角恢复。

SmartSub、下载组件及转写模型需单独安装。AI 整理在你确认后把选定的资料发送到所选服务。服务方的使用条款和费用适用。内附的 Sign-in with ChatGPT DevKit 适用非商业许可，见 `licenses` 目录。
