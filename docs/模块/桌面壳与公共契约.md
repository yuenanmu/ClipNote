# M01 桌面壳与公共契约

## 职责与边界

T07在文件工作台增加“API 设置”，受限IPC仅允许读取无密钥状态、保存配置、显式测试和取消。密钥通过密码输入传入可信主进程，Windows safeStorage加密落盘，不返回页面或写日志；新服务地址须输入新密钥。显式测试前展示接收地址/模型，发送固定合成文本，可能产生费用。真实分析及文件工作流按任务清单分别验收。

提供 Electron 主进程、React 界面入口、受限 preload、文件选择、系统外部打开及本地凭据保护。集中维护跨模块数据类型和 IPC 消息。后续 Windows 安装包在此确定启动与打包边界。

不承担字幕解析、提示词生成、CLI 业务流程或笔记版本保存。React 不直接读取密钥、运行 shell 或持有任意文件访问权。

## 输入、输出与关系

- 输入：用户操作、文件选择结果、模块命令和任务事件。
- 输出：受约束的主进程调用、界面状态、必要的配置摘要；凭据只返回非敏感状态。
- 调用 [M07](任务协调与恢复.md) 执行任务，调用 [M06](Markdown阅读.md) 直接阅读；为 [M04](AI分析.md) 提供受保护凭据存储及登录交互。
- 实际位置：`project/src/main/`、`project/src/preload/`、`project/src/contracts/`、`project/src/renderer/`。凭据产品化、完整任务流和打包属于后续任务。

## 当前导入接口

`window.clipnote.importSource(): Promise<ImportResult>` 不接收页面提供的路径或参数。主进程核对 sender 与主 frame，拒绝多余参数和重复请求，由系统文件选择框取得路径。结果区分 imported/document、cancelled、error/code/message；错误不透出任意异常正文。

存储桥接追加 `libraryState()`、`chooseLibrary()`、`saveSource(sourceId)`、`resumeSave(draftId)`、`openRevision(sourceId, revisionId)`。选择目录只来自系统选择框，页面仅传严格校验的已知 ID，不传任意路径或待保存正文。存储请求共用串行锁，返回 ok/value、cancelled 或固定 error（可含恢复草稿 ID）。完整契约见 `contracts/desktop.ts` 和 M05。

阅读桥接保留 `readerOpen()`、`readerRevision(sourceId,revisionId)`、`readerRefresh(readerId)`、`readerExternal(readerId)` 和 `readerLink(readerId,url)`。笔记区增加 `noteList()`、`noteAdd()`、`noteOpen(noteId)`、`noteRemove(noteId)`、`noteRelink(noteId)`、`noteSource(sourceId)`；系统选择/已导入 MD 之外不接收路径，移出只移除登记。主进程保存最多5个阅读会话及链接白名单，持久文件列表与会话独立，固定错误不透出底层异常。外部打开只接受会话已登记 Markdown，链接还须属于正文中的安全 HTTP(S)。详见 M06。

`source-worker.ts` 读取/解析来源，`storage-worker.ts` 保存与检查库，`reader-worker.ts` 读取 Markdown 并生成有界 AST；`WorkerTasks` 协调超时及关闭清理。来源快照的原始字节只保留在主进程侧五份缓存，不传给 renderer。页面禁用外部请求、导航及新窗口；来源按纯文本显示，Markdown 按白名单 AST 渲染，HTML/图片不获得执行和网络能力。主动外链交系统浏览器，AI 接入时再按任务明确调整网络边界。

`tools/build-desktop.mjs` 构建、`tools/start-desktop.mjs` 启动；main/preload/Worker 输出 CJS，兼容沙箱 preload。会话最多保留五份来源，归档版本由 M05 持久化。同一 userData 只允许一个应用实例，第二次启动退出并唤起已有窗口，避免多个进程共享保存设置与草稿。普通 GUI 启动器必须保持 windowsHide:false，原生控件回归见问题记录 P001。

## 核心约定

- 开启 contextIsolation/sandbox，关闭 nodeIntegration；界面仅访问白名单能力。
- 公共契约沿用架构中的 SourceDocument、Job、Profile 等名称；具体领域语义由所属模块维护，不能在 IPC 两端分别发明字段。
- 文件路径来源于受控选择或已登记的笔记，校验访问范围；不执行用户文本中的命令。
- API/OAuth 凭据在用户应用数据目录加密保存，刷新写入串行化；保护能力不可用时报错，不降为明文。
- pi-ai 的运行下限要与 Electron 内置 Node 一起验证；开发机 Node 能运行不等于安装包能运行。

## 错误与验收重点

窗口关闭、重复操作、桥接参数无效、文件取消选择、凭据解密失败、登录回调中断都需明确响应。界面不因耗时解析/CLI/网络调用而卡住；敏感值不经 IPC、日志或导出泄露。安装后在无开发 Node 的目标环境验证实际启动能力。
