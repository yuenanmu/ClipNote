# 新增模块模板

> 已有模块见[模块索引](模块索引.md)。这份模板仅供未来新增模块使用，不表示现有 M01～M07 尚未设计。实际进度统一见[任务清单](../任务清单.md)。

## 职责与边界

填写模块编号、名称、负责和不负责的能力，说明与项目范围的关系。

## 输入、输出与关系

填写消费/生产的公共契约、直接依赖、下游、计划或实际代码位置。未创建的代码路径须明确标记，不制作假文件链接。

## 核心约定与错误

说明契约归属、不变量、错误处理、敏感数据和生命周期，以及影响上下游的兼容性。

## 验收与关联任务

链接任务编号及验收入口，记录计划工作分支。测试命令未创建时明确未创建，不抄其他项目命令。

不在模块文档复制任务复选框、授权、状态表或完整验证日志；统一维护在任务清单。新增模块后更新模块索引、架构和任务依赖，并按 AGENTS 的独立分支、验证审阅与获批合并流程交付。
