# M07 任务协调与恢复

## 职责与边界

协调来源、分析、保存和展示，管理单个活动任务的阶段、检查点、取消、重试、手动服务切换及资源生命周期。向界面发出可理解的进度和错误。

不包含网站下载实现、字幕解析细节、提示词或存储原子性算法；这些由对应模块负责。纯阅读不创建分析任务。

## 输入、输出与关系

- 输入：用户来源选择、Profile、输出目录、开始/取消/重试，以及持久检查点。
- 输出：Job 阶段事件、GenerationAttempt 归属、SavedRevision 或保留成果及错误。
- 调用 [M02](文件来源.md)/[M03](SmartSub适配.md) 获取来源、[M04](AI分析.md) 分析、[M05](本地存储与版本.md) 保存；经 [M01](桌面壳与公共契约.md) 更新界面，成功后交 [M06](Markdown阅读.md)。
- 计划位置：`project/src/modules/jobs/`；尚未创建。

## 状态与恢复契约

阶段为等待、准备资源、获取来源、分析、合并校验、保存、完成；任何阶段都可进入失败或取消。文件任务跳过链接准备；单个活动任务，分块默认串行。

检查点至少含来源快照、各分块结果、合并结果和待保存结果；来源/模型/提示词变化才使受影响阶段失效，并记录原因。AI 失败不重下载/转写；保存失败不重跑 AI。

用户手动切换服务创建新尝试，复用来源但保留分块/合并的服务归属；不能混淆结果或自动转收费路径。恢复时校验检查点对应输入，不以标题认定同一任务。

取消只终止本任务能取消的操作，清理自己的轮询/句柄；SmartSub 上游不可中止阶段需如实显示，不强杀共享后台。完成、失败、取消都应结束轮询和无用监听。

## 错误与验收重点

分清输入、来源、资源、网络、鉴权/额度、结构/引用和保存错误，提示保留成果与恢复选项。验证关闭/重开、阶段中断、连续点击、取消后重试和保存换目录。

测纯阅读空闲、文件分析、已有字幕链接、转写四场景的 CPU/内存/磁盘及结束后的后台状态；没有实测前不承诺数值。文件/阅读不启动 SmartSub，只清理本任务拥有的资源。
