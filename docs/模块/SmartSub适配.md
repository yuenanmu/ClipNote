# M03 SmartSub 适配

2026-10-29 用户授权 T10，分支 `feat/smartsub`，实施与验收见[本轮计划](../superpowers/plans/2026-10-29-t10-smartsub.md)。用户确认 SmartSub 可使用，进程信息证实 3.10.1 正在运行；当前执行环境无法访问进程记录的安装路径，原因仍待核实。真实 CLI 未验，替身测试不代替真实接入。

当前实现通过主进程白名单查询版本、下载组件、本地引擎和模型；请求身份及外部任务身份保存在本地，查询和取消针对单个任务。字幕 SRT/VTT 使用原始文件及时间轴校验后进入现有资料/整理链。已有但不支持的字幕提示转换；无字幕且仅一个媒体时，显示本地引擎和模型，用户确认后才转写。云端转写及应用内安装资源尚未接入，缺资源时引导用户在 SmartSub 中自行确认和安装。

## 职责与边界

连接官方 SmartSub 的 CLI：发现/选择安装、检查版本和能力、按需准备依赖、提交来源任务、跟踪结果并读取字幕，最后产生与文件导入一致的 SourceDocument。

网站下载及识别由 SmartSub 及其上游工具负责。ClipNote 不逐站重做适配、不承诺任意网站可用，也不要求用户先填写网站清单。模块验收重点是 CLI 调用和结果接入；用少量上游支持的链接做真实冒烟验证。

## 输入、输出与关系

- 输入：URL、安装位置、资源选择和下载确认；必要时读取任务检查点中的外部 taskId。
- 输出：规范化字幕来源、任务/资源状态和可解释错误；流向 [M05](本地存储与版本.md)、[M04](AI分析.md)。
- 由 [M07](任务协调与恢复.md) 调度，通过 [M01](桌面壳与公共契约.md) 显示准备和授权交互。
- 实际位置：`project/src/modules/smartsub/`；发现、CLI、任务、字幕读取及本地转写已实现，真实接入验收以任务清单为准。

## CLI 与首次准备

研究基线为官方 v3.11.0；用户 fork 3.7.0 不作为当前 CLI 基线。安装目录中的 CLI 启动脚本依赖完整 SmartSub 程序，不能只复制脚本。版本与调用细节按上游契约核对，不假设私有内部接口稳定。

已有安装先检测或手动选择；没有时展示官方安装器信息，用户点击下载并完成一次安装，再重新检查。程序、下载器、模型与引擎分开检查；字幕优先，无字幕才转写。资源下载前显示用途、已知大小和位置，未知大小明确说明。

使用受约束参数及 JSON 输入/输出，区分 stdout 结果、stderr 日志、退出码与任务终态；不拼接任意 shell。保存外部 taskId，处理有界等待、重连和读取字幕。无需用户配置 PATH、另装 Node 或注册 MCP。

## 生命周期、错误与验收

文件任务不启动 SmartSub，链接任务不要求其 GUI 常开。已有共享后台可以复用，取消不结束整个共享程序；实际取消能力不足时显示真实状态。结束、失败或取消都停止本任务轮询、释放本任务句柄。

验证已有/未安装、空格和中文路径、版本不兼容、缺资源、拒绝下载、退出失败、无字幕、字幕读取失败、运行中取消和重启后恢复。安装器存在、模拟 CLI 或任务提交成功均不足以证明完整接入。

安装尚未完成时，契约研究可进行，真实调用保留未验证；不能把网站名单缺失当当前阻塞，也不能把 SmartSub 自身平台故障包装成 ClipNote 已处理成功。

## T10 联动体验重做

- 资料区的视频任务保留统一文件树；`SettingsPanel` 提供 AI 服务与 SmartSub 分类，安装位置由系统选择器保存，日常任务无需重复选择。
- `SmartSubPreferences` 单独保存 ClipNote 使用的本地引擎、模型，不改写 SmartSub 全局设置。受限桥接仅提供读取资源、保存选择；保存和提交均验证引擎就绪及模型已安装。未单独保存时沿用 SmartSub 本地默认配置，不自动下载或选择云转写。
- `smartsub-observer` 串行自动查询，失败退避、真实终态停止；切换视图保留任务组件与输入，关闭应用后通过已持久请求 ID 恢复查询。下载终态和转写状态分别展示，查询中断不等于任务结束。
- 转写查询与取消可以独立发出，仅记录更新串行提交，防止迟到的运行回执覆盖取消状态。尚未取得外部任务 ID 的提交仍需恢复原请求，不能伪称已取消。
- 合成 CLI、窗口和离线验证与真实 SmartSub 验收分开记录；计划及待验项见任务清单 T10 追加记录。

绑定任务通过一次操作连接取得身份和捕获同一安装的调用闭包；校验 journal 摘要后直接使用该连接，避免重复发现和重复 system.info。不同操作分别重新检查，持久摘要算法不变。
